# Django Login System

## 🔧 Features

- User Signup
- User Login
- View All Users (GET)
- View Single User by Email (POST)
- Update User Details (PUT)
- Delete User by Email (DELETE)
- Admin Interface for Superuser Management

## 📁 Project Structure

- **LoginSystem/** – Main Django project
- **Loginify/** – App handling all login logic and CRUD operations
- **templates/** – HTML templates for signup, login, and success pages
